\# 실험기구 이미지 인식을 통한 종합적 사용법 안내 서비스



\## 프로젝트 목적



사용자가 실험기구 이미지를 업로드하면

기구를 인식하고 이름, 용도, 구조, 사용법, 주의사항을 제공하는 웹 서비스를 제작한다.



\## Input



\- 실험기구 이미지 업로드

\- 필요시 실험 분야 선택



\## Process



\- 이미지 분석

\- 실험기구 후보 판별

\- 후보별 인식 신뢰도 제공

\- 사용자가 최종 기구 선택

\- Supabase에서 기구 정보 검색



\## Output



\- 실험기구 이름

\- 인식 신뢰도

\- 주요 용도

\- 구조

\- 사용 방법

\- 주의사항



\## 사용 기술



\- GitHub: 코드 저장 및 버전 관리

\- Vercel: 웹 서비스 배포

\- Supabase: 실험기구 정보 데이터베이스
