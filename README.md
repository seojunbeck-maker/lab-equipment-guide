\# 실험기구 이미지 인식을 통한 종합적 사용법 안내 서비스



\## 프로젝트 목적



사용자가 실험기구 이미지를 업로드하면

기구를 인식하고 이름, 용도, 구조, 사용법, 주의사항을 제공하는 웹 서비스를 제작한다.



\## Input



\- 실험기구 이미지 업로드

\- 필요시 실험 분야 선택



\## Process



\- 이미지 분석

\- 실험기구 후보 판별

\- 후보별 인식 신뢰도 제공

\- 사용자가 최종 기구 선택

\- Supabase에서 기구 정보 검색



\## Output



\- 실험기구 이름

\- 인식 신뢰도

\- 주요 용도

\- 구조

\- 사용 방법

\- 주의사항



\## 사용 기술



\- GitHub: 코드 저장 및 버전 관리

\- Vercel: 웹 서비스 배포

\- Supabase: 실험기구 정보 데이터베이스


\## 5회차 사전 검색 및 후보 비교 개선


\- 사전에 들어가면 검색어 없이 전체 실험기구 목록을 표시한다.

\- 세부 category는 보존하고 화면에서는 유리기구, 측정기구, 가열기구, 분리기구, 배양기구, 관찰기구, 기타로 묶어 표시한다.

\- `english_name`, `aliases`를 이용해 띄어쓰기와 대소문자를 무시한 한국어·영어 검색을 지원한다.

\- 검색 자동완성은 최대 5개 후보를 표시한다.

\- 이미지 분석은 Gemini를 한 번만 호출하고, 후보별 `key_features`는 Supabase에서 조회한다.

\- 1위와 2위 신뢰도 차이가 15% 이하이거나 1위가 70% 미만이면 특징 비교 안내를 표시한다.

\- `/api/equipment-list`는 `group_category`, `english_name`, `aliases`, `key_features`를 포함하며 `name`과 `category` query를 지원한다.


\## 6회차 사용자 인증 및 안정화


\- Supabase Auth 이메일 회원가입, 로그인, 로그아웃과 브라우저 세션 유지를 지원한다.
\- 회원가입은 Vercel 서버와 인증된 Supabase Edge Function을 통해 처리하여 기본 SMTP 제한과 무관하게 즉시 로그인된다.

\- 공개 사전과 이미지 분석은 로그인 없이 계속 사용할 수 있다.

\- `favorites`와 `analysis_history`는 `user_id`를 기준으로 사용자별 분리되며 RLS가 다른 사용자의 행 접근을 차단한다.

\- 개인 데이터 API는 브라우저의 Supabase access token을 검증한 뒤 동일 토큰으로 Data API를 호출한다.

\- 프론트에는 `SUPABASE_PUBLISHABLE_KEY`만 제공하며 secret/service role key는 노출하지 않는다.

\- 잘못된 파일, 실험기구가 없는 사진, 미등록 기구, 네트워크 오류를 한국어 안내로 처리한다.

\- 대표 기구 `시험관대`를 추가하고 `깔때기`, `집게` 별칭을 기존 데이터에 연결한다.


\## 사전 등록 제안과 관리자 검토


\- 사용자는 사전 화면에서 새 실험기구 정보를 제안할 수 있다.

\- 제안은 `equipment_submissions`에 `pending` 상태로 저장되며 공개 조회되지 않는다.

\- 관리자는 `#admin` 검토실에서 로그인한 뒤 제안을 승인하거나 반려한다.

\- 승인은 기구 등록과 제안 상태 변경을 하나의 데이터베이스 작업으로 처리한다.

\- 관리자 비밀번호, 세션 서명값, Edge Function 호출 토큰은 각각 `ADMIN_PASSWORD`, `ADMIN_SESSION_SECRET`, `ADMIN_EDGE_TOKEN` Vercel Secret으로만 보관한다.
